# Data: ADE20K-150 and PASCAL VOC 2012

We use two standard public segmentation benchmarks; both are used **frozen** for evaluation only (no
segmentation training). Point the environment variables at your local extracted copies.

## ADE20K-150 (`ADEChallengeData2016`)
Set `PMX_ADE_ROOT`. Expected layout:
```
ADEChallengeData2016/images/{training,validation}/*.jpg
ADEChallengeData2016/annotations/{training,validation}/*.png   # reduce_zero_label: 0=ignore, 1..150=class
```
We score the full 2000-image validation set, hold out 30 of the 150 classes as novel (five seeded
splits), and use a 600-image train cache to fit the post-hoc calibrators.

## PASCAL VOC 2012 (`VOCdevkit/VOC2012`)
Set `PMX_VOC_ROOT`. Expected layout:
```
VOCdevkit/VOC2012/JPEGImages/*.jpg
VOCdevkit/VOC2012/SegmentationClass/*.png        # 0=background, 1..20=object, 255=void
VOCdevkit/VOC2012/ImageSets/Segmentation/{train,val}.txt
```
20 object classes, 6 held out as novel.

## Frozen models
See `../MODELS.md` for the exact identifiers (`facebook/sam-vit-base`, `openai/clip-vit-large-patch14`,
and, for the dense-CLIP regime, OpenAI CLIP `ViT-B/16` via the external SCLIP checkout). The seen/novel
class splits themselves are shipped in `../splits/` and regenerated by `scripts/dump_splits.py`.
